## how we operate

- **money matters.** the studio is built to become sustainable, not famous.
- **small tools feed paid products.** free utilities are useful on their own, but every public surface should make the studio easier to trust.
- **claims must match reality.** if a product is in review, it says in review. if revenue is zero, we do not pretend otherwise internally.
- **privacy is product work.** less data, fewer permissions, clear retention, working unsubscribe, working refund paths.
- **owned web first.** browser, WP, Reddit, GitHub, npm, and game platforms are distribution surfaces, not the center of the company.
- **no Russian platforms.** no Newgrounds. no Kongregate. no lifetime-deal dependency.
